# 🚦 RUAS-SIPIL - AI Traffic Analytics & Evaluation System

Aplikasi analisis arus lalu lintas berbasis AI (YOLOv8 & ByteTrack) dan evaluasi kinerja jalan berdasarkan standar **PKJI 2023**.

## 📥 Unduh Aplikasi (Siap Pakai / Portable)
Bagi pengguna umum yang ingin langsung menjalankan aplikasi tanpa instalasi Python:

👉 **[KLIK DI SINI UNTUK MENGUNDUH RUAS-SIPIL PORTABLE (v1.0.0)](https://github.com/annisaanindyah07/RUAS-SIPIL/releases/download/v1.0.0/RUAS-SIPIL_v1.0_Portable.zip)**

---

### 🚀 Cara Menjalankan:
1. Unduh berkas `RUAS-SIPIL_v1.0_Portable.zip` melalui link di atas.
2. Ekstrak (*Extract All*) file `.zip` tersebut di komputer Anda.
3. Buka folder hasil ekstrak, lalu klik 2x pada file **`jalankan_aplikasi.bat`**.
4. Aplikasi akan otomatis terbuka di browser Anda.

---

## 📊 Fitur Utama
- **Deteksi Dual Lane:** Pemisahan analisis Jalur Kiri (Arah A) & Jalur Kanan (Arah B).
- **Standar PKJI 2023:** Perhitungan Kapasitas Dasar ($C_0$), Derajat Kejenuhan ($DJ$), dan klasifikasi kendaraan (Motor, Mobil, Truk, Bus, Tak Bermotor).
